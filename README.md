## 🚀 Proyectos Destacados

### 1. [A.R.I.A] — Asistente Personal de IA & Sistema Agéntico de Voz
* **Stack:** Python 3.12, FastAPI, WebSockets, PyTorch/TFLite, SQLite, Docker, PyQt6, Capacitor (Android), ESP32 (C++).
* **Descripción:** Asistente personal multimodal con procesamiento de voz en tiempo real (STT/TTS), orquestación de LLMs y ejecución dinámica de herramientas del sistema (*Tool Calling*) bajo políticas de seguridad. Incluye memoria persistente en SQLite, capacidades de autoaprendizaje y modelos TFLite INT8 optimizados para inferencia local en satélites de voz con ESP32.

### 2. [eSports Manager] — Aplicación Móvil Híbrida (Android / Google Play Store)
* **Stack:** Capacitor, React 19, TypeScript, Vite, Firebase (Firestore), Recharts.
* **Descripción:** Aplicación móvil multiplataforma orientada a la gestión de torneos de esports con generación automática de brackets (Eliminación Directa, Doble Eliminación, Round Robin), motor de métricas estadísticas y sincronización en tiempo real con Firestore con arquitectura *Offline-First*.

### 3. [English Lab Web] — Plataforma Web Educativa (Emprender Ediciones)
* **Stack:** Astro, TypeScript, HTML5/Tailwind CSS, Hostinger.
* **Descripción:** Sitio web SSG de alto rendimiento optimizado para la enseñanza preescolar de inglés. Cuenta con un visor interactivo de libros con efectos 3D (FlipBook), reproductor de audio con i18n integrado para 76 pistas (canciones y fonética) y despliegue optimizado con certificación SSL.

### 4. [Pet-Feeder-IoT] — Dispensador Automático de Alimentos
* **Stack:** C++, ESP32, PlatformIO, Driver A4988, MQTT, Flutter (App Móvil).
* **Descripción:** Sistema embebido IoT diseñado para la dispensación automatizada de alimento para mascotas mediante arquitectura distribuida. Incluye sincronización horaria NTP, provisión de red mediante Bluetooth Low Energy (BLE) y control de motores paso a paso con gestión térmica de drivers.
